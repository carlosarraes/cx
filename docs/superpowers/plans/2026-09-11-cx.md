# cx implementation plan

**Goal:** A Rust `cx` with cs-compatible account commands and bare-command native Codex launch, supporting account changes between turns.

**Spec:** ../specs/2026-09-11-cx-design.md

**Architecture:** Private state transactions coordinate credentials; each invocation owns a Codex app-server and forwards the native TUI over a private transport. A local control socket applies selections to idle sessions and queues busy sessions.

**Constraints:** Linux/macOS first, ChatGPT OAuth, shared Codex history/settings, no token output, no automatic rotation in version 0.1. No mutations of real user credentials during automated verification. User requested the cs Justfile be copied.

## Task 1: Account storage, authentication, usage

Own `src/state.rs`, `src/auth.rs`, `src/usage.rs`, and their tests. Implement serializable account identity and tokens, atomic locked state, current/previous selection and alias validation. Delegate login to isolated Codex homes, serialize refresh, distinguish credential storage modes. Fetch bounded-time usage and choose eligible accounts without treating missing observations as zero.

Interfaces shared with the runtime and CLI:

## Task 2: Managed runtime

Own `src/runtime.rs` and `tests/runtime.rs`. Public interface `runtime::run(paths: Paths, codex: OsString, args: Vec<OsString>) -> Result<i32>`, `runtime::notify(paths: &Paths) -> Result<Vec<SessionStatus>>`, `runtime::sessions(paths: &Paths) -> Result<Vec<SessionStatus>>`. Sync facade around a Tokio runtime is permitted so blocking credential operations stay outside async executor threads.

- [x] Write failing tests for busy-turn pending selection and namespaced request handling.
- [x] Implement isolated app-server stdio child plus private Unix WebSocket transport to native `codex --remote unix://PATH`. Authenticate before forwarding the TUI handshake, synthesize the already-initialized handshake response, and relay native messages unchanged thereafter. Private control sockets accept only selection/status messages, never raw tokens.
- [x] Apply account login RPCs only at turn boundaries, coordinate refresh callbacks, and record actual/pending/failed status.
- [x] Bound control replies and child startup, clean sockets and reap children on exit. Fail closed on incompatible protocol.
- [x] Exercise actual transports with a fake Codex process and the installed Codex schema.
